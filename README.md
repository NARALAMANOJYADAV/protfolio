# Narala Manoj - Portfolio

Professional portfolio of Narala Manoj, a B.Tech student in AI & Data Science, specializing in Python, Java, and Full-Stack development.

## Technologies

- **Frontend**: React, Tailwind CSS, shadcn-ui
- **Backend**: Python, Java
- **Build Tool**: Vite
- **Language**: TypeScript

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

The application will be available at `http://localhost:8080`.

## Features

- Dynamic project showcase
- Responsive design
- Modern UI/UX with shadcn components
